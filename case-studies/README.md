# MNCS research case studies

A favorable development result is not automatically a formal MNCS or MNCDS claim. Each study states its evidence and promotion boundary.

- [EdgeStream](edgestream/README.md) — bounded C11 telemetry processing.
- [Remote Water Control](remote-water-control/README.md) — supervisory-control digital twin.
- [CacheForge](cacheforge/README.md) — Python LLM KV-cache planning.
- [Multilingual Stream](multilingual-stream/README.md) — one C11/Rust behavioral contract.
- [Go Gateway](go-gateway/README.md) — worker-pool, cancellation, race, and fuzz evidence.
- [Composed Gateway](composed-gateway/README.md) — C11 native FFI, generated Go binding, Go host, Rust authority, measured recovery, evidence custody, claim readiness, and portable physical-host reproduction.
- [RAVEL](ravel/README.md) — recursive adaptive vector execution.
- [dSense Desk Pet](dsense-desk-pet/README.md) — constrained Arduino evidence study.
