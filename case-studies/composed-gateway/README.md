# Composed C11/Rust/Go gateway

This bounded Wave Two system genuinely composes three languages. A C11 parser validates decimal frames through a stable C ABI. A generated Go binding carries the header and ABI identity. A Go host owns queue, timeout, process lifecycle, checkpoint, and rollback authority. A Rust subprocess validates proposals through the versioned `V1` line protocol.

The native and process boundaries have first-class identity, ownership, width, error, timeout, cancellation, malformed-input, compatibility, and UNKNOWN records. `FAIL > UNKNOWN > PASS`; required UNKNOWN yields `REVIEW_REQUIRED` only under the explicit composition policy. Formal MNCS and MNCDS status remain `UNKNOWN`, and D4 is unclaimed.
