# Machine-Native Complexity Standard

MNCS is an open, experimental, community-developed, tool-neutral standard for
accepting machine-generated implementations whose internals may exceed ordinary
human-maintainability limits.

**Human readability is relocated, not eliminated.** Readable control moves to the
contract, reference behavior, limits, policy, evidence, provenance, regeneration,
and rollback. Complexity is acceptable only for a predeclared measurable benefit.

[Read the introduction](introduction.md) or [validate an example](quickstart.md).
MNCS is not an accredited ISO, ANSI, IEEE, IETF, or similar standard.
