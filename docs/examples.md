# Examples

- **minimal** — accepted MNCS-L1 identity transform.
- **http-chunked-decoder** — compact MNCS-L4 conceptual parser bundle grounded in the
  bounded research task, without copied transcripts.
- **rejected-candidate** — valid L4 rejection because benefit is below threshold.
- **repair-workflow** — L3 exception-driven repair with a compact structural witness.
- **structural-provider** — L3 provider-neutral result and provider registration.

Run all examples with `./scripts/verify-examples`. Their small evidence files are
illustrative acceptance records, not proof that the toy implementations are suitable
for production.
