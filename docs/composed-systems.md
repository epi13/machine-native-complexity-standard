# Experimental composed systems

Wave Two selects Go because cancellation, bounded worker pools, race instrumentation, module identity, and reproducible deployment are directly relevant to the study. A profile is evidence metadata, not a compliance claim.

Every component and boundary keeps an independent result. Required `FAIL` dominates; otherwise required `UNKNOWN` propagates. A policy may label the system `REVIEW_REQUIRED`, but never `PASS`, while required evidence is unknown. Native FFI and process boundaries bind interface source, generated output, generator, ownership, integer widths, containment, timeout, cancellation, malformed input, compatibility, tested failures, and residual unknowns.

Generated bindings are regenerated deterministically and drift checked before compatibility tests. Rollback uses the readable Go authority. D4 is unclaimed because an independently witnessed release replacement drill has not been performed.
