# Introduction

Source review works best when humans can hold an implementation in mind. Generators
can produce correct and useful programs beyond that limit, but accepting opaque code
without a replacement control system is unsafe.

MNCS supplies that replacement: a readable human control layer and an immutable
machine execution layer. The evidence burden grows with opacity and risk. Five
cumulative levels separate behavioral, safety, structural, performance, and
regeneration claims so users can state exactly what was established.

The standard does not celebrate complexity. It makes complexity carry its lifecycle
cost and rejects it when a simpler candidate provides equal evidence and benefit.
