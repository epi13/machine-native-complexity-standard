# MNCS 0.1 specification

The normative specification is maintained in
[`spec/MNCS-v0.1.md`](https://github.com/epi13/machine-native-complexity-standard/blob/main/spec/MNCS-v0.1.md)
with its linked modules. The repository
copy, release tag, and manifest schema together identify the experimental 0.1
standard.

Validator/schema patch 0.1.1 is the current evidence-mechanics profile. It keeps
the MNCS 0.1 normative family while replacing self-asserted acceptance in new
manifests with content-addressed observations and validator-derived gates. Frozen
schema 0.1 remains available for explicit legacy validation.

Key requirements are two layers, cumulative levels, content-addressed evidence,
three-valued results, predeclared benefit, provider neutrality, regeneration, and
rollback. The specification is licensed Apache-2.0.

MNCS remains experimental. A validator PASS is scoped to the declared contract and
environment and is not accredited certification.
