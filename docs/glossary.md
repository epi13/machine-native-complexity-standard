# Glossary

**Acceptance policy** — explicit three-valued gates deciding the candidate result.
**Candidate** — immutable machine implementation under evaluation.
**Complexity profile** — multidimensional benefit, complexity, cost, and risk record.
**Evidence bundle** — canonical content-addressed claim directory.
**Human control layer** — readable contract, oracle, limits, policy, and lifecycle.
**Machine execution layer** — generated artifact, identity, provenance, and evidence.
**Pareto dominance** — no worse on every dimension and better on at least one.
**Provider** — a tool or method producing invariant evidence.
**UNKNOWN** — neither PASS nor FAIL established; never implicit PASS.
