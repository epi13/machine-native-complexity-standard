# Normative language

Capitalized MUST, MUST NOT, REQUIRED, SHALL, SHALL NOT, SHOULD, SHOULD NOT,
RECOMMENDED, MAY, and OPTIONAL carry the meanings defined in
[`spec/normative-language.md`](https://github.com/epi13/machine-native-complexity-standard/blob/main/spec/normative-language.md).

PASS means sufficient bounded evidence. FAIL means demonstrated violation or failed
gate. UNKNOWN means neither was established because of uncertainty, unsupported
analysis, failure, exceeded bounds, or missing evidence. UNKNOWN never silently
counts as PASS.
