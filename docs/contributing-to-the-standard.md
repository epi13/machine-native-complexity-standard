# Contributing to the standard

Corrections use ordinary issues and pull requests. Normative meanings, schemas,
levels, and governance use an RFC with public review. Contributions should include
compatibility, security, vendor-neutrality, tests, and evidence.

Run:

```bash
python -m pip install -e '.[dev]'
make check
```

Read the repository [contribution guide](https://github.com/epi13/machine-native-complexity-standard/blob/main/CONTRIBUTING.md),
[governance model](https://github.com/epi13/machine-native-complexity-standard/blob/main/GOVERNANCE.md),
and [RFC process](https://github.com/epi13/machine-native-complexity-standard/blob/main/rfcs/README.md).
Do not submit secrets or evidence you cannot redistribute.
