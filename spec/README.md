## MNCDS

Development-process guidance is maintained separately by the
[Machine-Native Complexity Development Specification (MNCDS)](https://github.com/epi13/machine-native-complexity-development-specification).

The files below are relocation pointers, not a second authoritative copy:

- [`MNCDS-v0.1-draft.md`](MNCDS-v0.1-draft.md)
- [`MNCDS-v0.1-rc.1.md`](MNCDS-v0.1-rc.1.md)
- [`MNCDS-v0.1-records-and-decisions.md`](MNCDS-v0.1-records-and-decisions.md)

MNCS may consume an MNCDS result as a companion object. It does not own MNCDS
meaning, and it does not require MNCDS to define MNCS implementation-evidence
acceptance.

MNCS and MNCDS claims remain separate. A project may publish both only when each result is
independently supported.
