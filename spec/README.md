# Specifications

## MNCS

- [`MNCS-v0.2.md`](MNCS-v0.2.md) — current experimental implementation-conformance standard.
- [`MNCS-v0.3-rc.1.md`](MNCS-v0.3-rc.1.md) — controlled-system-assurance
  release-candidate proposal under Draft RFC 0005.
- Linked modules define normative language, canonicalization, attestations, trust,
  reproducible packages, provider protocol, and related semantics.

## MNCDS

- [`MNCDS-v0.1-draft.md`](MNCDS-v0.1-draft.md) — proposed development lifecycle and cumulative profiles.
- [`MNCDS-v0.1-rc.1.md`](MNCDS-v0.1-rc.1.md) — independently consumable
  release-candidate proposal under Draft RFC 0004.
- [`MNCDS-v0.1-records-and-decisions.md`](MNCDS-v0.1-records-and-decisions.md) — proposed aggregate record and initial decision semantics.

MNCDS remains Draft under RFC 0004. The RC schema, two independent consumers,
tests, examples, and corpus are implementation evidence for review and do not
establish accepted core status.

MNCS and MNCDS claims remain separate. A project may publish both only when each result is
independently supported.
