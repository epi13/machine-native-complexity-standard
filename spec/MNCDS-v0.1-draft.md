# MNCDS specification relocated

The Machine-Native Complexity Development Specification is now maintained in
its own repository:

https://github.com/epi13/machine-native-complexity-development-specification

Canonical file:

https://github.com/epi13/machine-native-complexity-development-specification/blob/main/spec/MNCDS-v0.1-draft.md

MNCS retains only this pointer so the standard remains focused on
implementation-evidence acceptance. MNCS does not depend on MNCDS to define
its own normative requirements. Combined assurance-case objects may still
reference an MNCDS result without embedding the development specification.
